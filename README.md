# Ollama Local LLM Inference

## Week 5 - Day 2

This project demonstrates local LLM inference using Ollama.

## Models Used

- llama3.2:3b
- qwen2.5:3b

## Tasks

1. Call Ollama API using Python.
2. Use a custom system prompt.
3. Test five different prompts.
4. Compare llama3.2:3b and qwen2.5:3b.
5. Document response quality differences.

## Requirements

- Python
- Ollama
- llama3.2:3b
- qwen2.5:3b
- requests

## Run Inference

```bash
python ollama_inference.py
```
