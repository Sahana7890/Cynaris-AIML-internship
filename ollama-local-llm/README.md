# Running LLMs Locally with Ollama

## Objective

This project demonstrates how to run Large Language Models locally using Ollama and perform local inference using Python.

## Models Used

- Llama 3.2 3B
- Qwen 2.5 3B

## Technologies

- Python
- Ollama
- Llama 3.2 3B
- Qwen 2.5 3B

## Tasks Completed

### Task 1 - Ollama Installation and First Inference

Installed Ollama and pulled the Llama 3.2 3B model.

```bash
ollama pull llama3.2:3b
ollama run llama3.2:3b
```
